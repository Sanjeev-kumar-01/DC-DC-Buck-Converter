# DC-DC-Buck-Converter

Buck Converter Hardware Implementation

This project presents the design and implementation of a Buck Converter to study its operation in CCM, BCM, and DCM. The converter was assembled on a PCB and tested using an oscilloscope. Experimental results were compared with MATLAB/Simulink simulations to verify converter behavior under different load conditions.

#  Features

-  Hardware implementation of a Buck Converter
-  Gate Driver PCB integration
-  Operation in CCM, BCM, and DCM
-  Oscilloscope-based waveform analysis
-  MATLAB/Simulink verification
-  Experimental study of switching-node ringing in DCM



#  Hardware Components

- MOSFET
- Fast Recovery Diode
- Inductor
- Capacitors
- Gate Driver PCB
- Oscilloscope
- DC Power Supply
- Variable Load Resistance
